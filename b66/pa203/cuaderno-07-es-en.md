# PA-203 · Cuaderno 07 · Verificación y privacidad / Verification and privacy

## Español
**Actividad:** Analiza un texto ficticio generado con IA. Selecciona tres afirmaciones y crea una tabla con afirmación, fuente verificable, fecha y estado (confirmada, pendiente, falsa). Elimina nombres, teléfonos y correos reales antes de copiar información en herramientas de IA. Redacta una versión corregida que diferencie hechos y suposiciones.

**Evidencias:** borrador inicial, resultado revisado, explicación de cambios y autoverificación.

**Preguntas de reflexión:** ¿Qué datos deben verificarse? ¿Qué decisiones requieren revisión humana?

## English
**Activity:** Review a fictional AI-generated text. Select three claims and make a table with claim, verifiable source, date, and status (confirmed, pending, false). Remove real names, phone numbers, and emails before using AI tools. Write a corrected version that separates facts from assumptions.

**Evidence:** initial draft, revised result, explanation of changes, and self-check.

**Reflection:** Which details require verification? Which decisions need human review?

**Criterios / Criteria:** claridad / clarity; exactitud / accuracy; privacidad / privacy; reflexión / reflection.
