# B87 Prototipo de monetización — Implementation Plan

**Goal:** Preparar en rama de prueba PLUTÓN Hoy separado de Noticias, tres herramientas laborales y una tienda empresarial para revisión de Ruslan.

**Architecture:** Prototipo estático independiente en `b87-prueba/`. No integrar aún en la portada o aula. Separar funciones puras de generación y cálculos, interfaz y estilos. Los datos de usuario permanecen en memoria y las descargas requieren acción explícita.

**Tech Stack:** HTML, CSS y JavaScript sin dependencias de producción. Node test para lógica y comprobaciones DOM aisladas para interacción.

**Spec:** Alcance autorizado en la conversación del 20 de octubre de 2026, documentado en `b87-prueba/README.md`.

- Datos vacíos o importes inválidos: validación de formulario y lógica.

- Muestras, formatos y precios: distinguir demostración de producto comercial terminado.
- Red y despliegue: ningún fetch, servicio de pago o acción de publicación.
